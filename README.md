# PyAutoInsight

One dashboard and one ongoing chat for inference campaigns.

[Dashboard](https://pyautolabs.github.io/PyAutoInsight/) · [Check in](CHECKIN.md) ·
[Contract](REFERENCE.md) · [Campaigns](campaigns.yaml)

Copy the editable prompt at the top of the dashboard unchanged for a full sweep.
Add a campaign focus or idea before or after it; the overall sweep remains.
Tracked campaigns are not evidence of running jobs. The organ owns coordination;
Cortex records scientific observations and human conclusions, and projects retain
raw samples and execution. Mind tracks bounded implementation PRs and claims.

```bash
python3 -m pip install pyyaml
bin/pyauto-insight board
bin/pyauto-insight check --offline
bin/pyauto-insight census
```

The first real producer is autolens_inference. A second-producer fixture tests
interoperability; it is not a claim of a second adopter.
